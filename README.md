# File Vault

Микросервис одноразовых зашифрованных ссылок (аналог Mozilla Send). Пользователь загружает текст или файл, сервис шифрует его на бэкенде, сохраняет и выдаёт уникальную ссылку по UUID. Ссылка автоматически "сгорает" после первого открытия или по истечении TTL.

## Возможности
- Шифрование содержимого на бэкенде (Fernet, ключ берётся из переменных окружения).
- Одноразовое чтение: после первого скачивания запись атомарно удаляется из хранилища.
- Автоматическое уничтожение по TTL (время жизни задаётся при создании ссылки).
- Поддержка как текстовых секретов, так и файлов.
- Подробное сквозное логирование (консоль + ротируемые файлы).
- Интерактивная документация API (Swagger/OpenAPI).
- Запуск одной командой через Docker Compose.

## Стек
- **Python 3.12**, **FastAPI**, **Uvicorn**
- **Redis** — хранилище секретов с нативным TTL и атомарным удалением при чтении
- **cryptography (Fernet)** — шифрование на бэкенде
- **pydantic-settings** — конфигурация через переменные окружения
- **ruff** — статический анализ кода
- **pytest** — тесты

## Структура проекта
```
app/
  core/          # конфигурация, логирование, шифрование
  api/v1/        # HTTP-роуты
  schemas/       # Pydantic-модели запросов/ответов
  services/      # бизнес-логика
  repositories/  # доступ к данным (Redis)
static/          # демо-фронтенд
tests/           # unit и integration тесты
```

## Быстрый старт
```bash
cp .env.example .env
# при необходимости сгенерировать ключ шифрования:
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

docker compose up --build
```

После запуска:
- API: http://localhost:8000
- Swagger UI: http://localhost:8000/docs

> Разделы «Архитектура» и «Переменные окружения» будут дополнены по мере готовности сервиса.
